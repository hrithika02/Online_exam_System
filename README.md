# Online Exam System

A full-stack Online Exam System built using React and Spring Boot. The system allows administrators to create and manage exams, while students can securely take exams and view their results.

## Tech Stack

- Frontend: React.js
- Backend: Spring Boot
- Database: MySQL
- Version Control: Git & GitHub

## Features

- User Authentication
- Admin Dashboard
- Student Dashboard
- Exam Management
- Question Management
- Automatic Result Evaluation
- Timer-Based Exams
